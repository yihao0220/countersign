# 已确认：Owner 管理 Agent 权限

## 行为

用户批准：Owner 立即撤销 Agent 付款权限；新增和重新授权等待 120 秒，再执行。初始 Agent 在构造时授权。
多个授权 Agent 共用总预算、每日上限与已付标识，不因新增地址获得额度。撤销一个不影响其他 Agent；全局暂停继续拦截全部 Agent。
撤销同时取消同地址待执行授权，避免旧申请重新打开权限。取消或执行过的记录不可重放，重新排队重新等待。

## 接口与约束

authorizedAgents 是当前权限真相；agent 保留原查询入口且仅代表初始地址。构造函数五个参数保持不变。
queueAgentAuthorization / revokeAgent 仅 Owner；执行与取消沿用 execute / cancel。每个地址一项 pending，不同地址独立。
零地址、Owner 地址、已授权地址不可排队；撤销没有权限且没有 pending 的地址返回错误。
操作事件记录申请、执行、取消、撤销。未授权付款回滚为 UnauthorizedAgent，不生成 Blocked。
权限管理与 execute 同样受重入保护；不清空账目、不补预算、不修改有效期、不解除暂停。
