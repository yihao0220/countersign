## 接入边界

Vite 把 `/api/login`、`register`、`me`、`logout` 和 `auth-health` 同源代理到 Node，其余 `/api` 到 Python。Node 用 APP_ORIGIN 核对浏览器写请求。Python 配置 COUNTERSIGN_AUTH_URL 后，对全部 `/api/` 请求调用 Node `/api/me` 检查会话；无效会话返回 401，认证服务不可用时返回 503，不放行。两个服务间只使用本机 HTTP。公开健康检查不返回业务数据。

`local.sh` 自动配置会话检查。独立合约/HTTP 测试保留不启用认证的测试入口；自行启动 uvicorn 不设置 COUNTERSIGN_AUTH_URL 不等于获得了登录保护，不能据此发布服务。

所有账户共用本地演示工作区，没有组织、租户或用户数据隔离。登录只验证工作台账户；控制台保留连接状态、Owner 地址、正确网络、链上 ready 的检查。可选择的 Anvil 测试账户仍是无价值解锁身份，不是生产 Owner 授权、真实钱包签名或账户到链上角色绑定。

此版没有邮箱验证、密码找回、多因素认证或生产角色管理，保留附件的单进程账户文件/会话实现。依然没有真实 AI/OCR、真实奖金、公链或真实资金接入。
